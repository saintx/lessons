# lessons

Code and data behind the series on [saintx.dev](https://saintx.dev).

A series is a branch. A post is a tag. Fetch from the branch tip, then check out the tag.

| Series | Branch | First post |
| --- | --- | --- |
| surf | `surf` | `surf/0001-traverse-context` |

```bash
git clone https://github.com/saintx/lessons.git
cd lessons
git switch surf
./fetch
```

Then check out the tag the post names.
